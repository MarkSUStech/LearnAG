# 标题字体

`noto-sans-sc-heading.woff2` 来自 Google Fonts 的 Noto Sans SC 600，遵循同目录 SIL Open Font License (`OFL.txt`)。2026-10-19 通过官方 CSS API 的 `text` 参数生成 16,720 字节子集，用于初稿的中文标题、AI 展示标题与 LearnAgent 字标。构建后本地提供，不产生运行时 Google Fonts 请求。

源 CSS 记录在 `.impeccable/references/noto-heading.css`。字形范围为：

```
ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789 相邻交换与逆序对笔记与资料知识图谱学习路径一起想清楚先观察再推导最后自己试从一个问题开始随机变量分布函数工作台设置外观把好像懂了变成真正理解
```

用户笔记中的其他汉字回退至现有中文字体；正式采用该设计时应依据实际语言范围提供完整分段字库。正文沿用系统字体，不增加长篇阅读的字体下载负担。
