# 位运算（Bitwise Operations）

## 1. 场景引入

你面前有一组数据，要判断其中**有没有重复**——最朴素的做法是开一个字典计数。但只要数据范围有限（比如所有数都在 `0~31` 之间），可以用一个 32 位的**整数**当作"位图"：第 `i` 位是 1，就代表数字 `i` 出现过。背后的核心就是**位运算**——用二进制位的"开关"代替复杂的数据结构。

## 2. 核心定义

> 💡 **位运算**（Bitwise Operation）：直接对整数在内存中的**二进制位**（bit）进行操作的运算，速度远快于普通算术与比较。

| 运算符         | 名称         | 规则（一句话）                  | 类比          |
| ----------- | ---------- | ------------------------ | ----------- |
| `&`         | 与 AND      | 同 1 才 1，否则 0             | 串联开关：两个都按才亮 |
| `\|`        | 或 OR       | 有 1 即 1                  | 并联开关：任一按就亮  |
| `^`         | **异或 XOR** | 不同为 1，相同为 0              | 跷跷板：不一样才"动" |
| `~`         | 取反 NOT     | 0 变 1，1 变 0              | 反向器         |
| `<<` / `>>` | 左/右移       | 整体向左/右挪 n 位，等价 ×2ⁿ / ÷2ⁿ | 排队左右挪       |

## 3. 原理拆解：重点讲透 XOR

### 3.1 XOR 的三条灵魂性质

1. **自反性**：`a ^ a = 0`（自己和自己异或归零）
2. **恒等性**：`a ^ 0 = a`（和 0 异或不变）
3. **交换 / 结合**：`(a ^ b) ^ c = a ^ (b ^ c)`

> 一句话记忆：**异或就是"无进位加法"**——对应位相加但不进位。

### 3.2 经典应用：找出只出现一次的数

> 给定一个非空整数数组，除了某个元素只出现一次外，其余每个元素都出现两次。找出那个只出现一次的数。

**思路**：把数组里所有数全部异或一遍。利用性质 1，相同的数两两抵消为 0；再利用性质 2，剩下的就是答案。

```python
def single_number(nums):
    ans = 0
    for x in nums:
        ans ^= x
    return ans

print(single_number([4, 1, 2, 1, 2]))  # 4
```

时间 $O(n)$，空间 $O(1)$——比哈希表省一截。

### 3.3 其他高频应用

* **交换两个变量**：`a, b = a ^ b, (a ^ b) ^ b`（推导：先存 `a^b`，再分别还原）
* **判断两数是否相等**：`a ^ b == 0`（不产生分支，CPU 友好）
* **找缺失的数字 / 找出现奇数次的数**：思路同 §3.2

## 4. 关键结论

* 位运算是 CPU 的"原生指令"，速度比算术运算快一个量级。
* XOR 的三大性质是解题核心：**自反、恒等、交换结合**。
* "无进位加法"是理解 XOR 的最佳物理图像。
* 位运算常用于**位图**、**状态压缩**、**找唯一元素**、**快速判断相等**。
* 在 Python 中参与位运算的应是**整数**，负数用二进制补码表示，移位时需留意。

## 5. 易错警示

| ❌ 误区                     | ✅ 正确                                                   |
| ------------------------ | ------------------------------------------------------ |
| `^` 是"幂次"（像数学里的指数）       | 在 Python 中 `^` 是**按位异或**，幂次是 `**`                      |
| `1 << 32` 在所有语言里都是 `2³²` | Python 整数**没有位数上限**，会真给 `4294967296`；C/Java 中是 UB（未定义） |
| 用 `>>` 代替 `/2` 一定更快      | 对**正数**等价且更快；对**负数**Python 是算术右移（向下取整），C 是实现定义的        |

## 6. 典型示例

### 示例 1：缺失的数字

```python
def missing_number(nums):          # nums 是 0..n 中缺一个的 n 个数
    n = len(nums)
    ans = n                        # 末尾把 n 也算上
    for i, x in enumerate(nums):
        ans ^= i ^ x
    return ans
```

### 示例 2：判断是否为 2 的幂

```python
def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0
```

> 原理：2 的幂二进制只有一个 1，`n-1` 会把这个 1 借位成 0，AND 后必为 0。

## 单元巩固

**核心小结**

* 位运算：`&` `|` `^` `~` `<<` `>>` 六兄弟。
* XOR 三性质：自反、恒等、交换结合。
* 经典套路：**全员 XOR 找唯一**；**`n & (n-1)` 判 2 的幂**。

**思考练习**

1. 不用额外变量，如何用 XOR 交换 `a` 和 `b`？写出三行表达式并验证。
2. 一个数组中**有两个**数各只出现一次，其余都出现两次，能否只用 $O(1)$ 空间找出它们？提示：先把全员 XOR 得到 `s = a ^ b`，再按某一位把数组分两组。
