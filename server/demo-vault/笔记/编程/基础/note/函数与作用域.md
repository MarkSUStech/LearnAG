# 函数与作用域

## 一句话定义

函数是封装了可复用逻辑的代码块；作用域决定了名字在哪些代码区间可见。

## 要点小结

* Python 的作用域查找顺序：局部 → 外层函数 → 全局 → 内置（LEGB）；
* 函数是一等公民：可以赋值给变量、作为参数传递；
* 参数默认值只在定义时求值一次（可变默认值是经典陷阱）。

## 作用域示意

```mermaid

    G["全局作用域"] --> F["函数作用域"] --> I["内层嵌套作用域"]

    F -. 继续向外 .-> G
```

> 图注：LEGB 查找链——名字解析由内向外。

## 典型示例

```python
count = 0            # 全局

def make_counter():
    n = 0            # 外层函数局部
    def inc():
        nonlocal n
        n += 1
        return n
    return inc

c = make_counter()
print(c(), c())      # 1 2 —— 闭包记住了 n
```

## 我的易错点

* 在函数内给全局变量赋值却忘了 `global` 声明；
* 可变对象作默认参数：`def f(x, acc=[])` 会跨调用共享列表；
* 混淆"返回函数"与"调用函数"。
