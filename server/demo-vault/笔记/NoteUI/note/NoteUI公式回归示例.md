# 括号库存：公式与交互混排

串 $)^{a_i}(^{b_i}$ 进入时，左边有 $a_i$ 个右括号，右边有 $b_i$ 个左括号。所有上下标都位于同一个数学环境内。

<!-- ui:steps mode=steps title="库存 $a_i$ 与 $b_i$" -->

1. 进串
    手里有 `cur` 个可用 `(`；这一串左边有 $a_i$ 个 `)` 在等着配。
2. 吃掉
    最多吃掉 $\min(cur, a_i)$ 对；没吃上的 `)` 永久作废。
3. 出串
    右边 $b_i$ 个 `(` 加入库存。**串内自身得分恒为 0**。

<!-- ui:steps mode=timeline -->

1. **库存 $cur$** 与 \(a_i\)

    配对数量为 $u=\min(cur,a_i)$。

2. **更新 $cur\gets cur-u+b_i$**

    说明中的 `cur` 保持行内代码。
