# 一次完整的学习：理解线性回归

这篇演示笔记展示 NoteUI 的 20 类组件。**实验指标、完成进度和日程均为演示数据**，不代表实际学习记录。正常笔记只选择有帮助的少数组件，普通段落始终是主体。

## 理解：建立概念和层次

<!-- ui:concept title="先把概念说清楚" -->

| 术语 | 定义 | 容易混淆 |
|---|---|---|
| 参数 | 由训练拟合的模型系数，例如 $w$ 和 $b$ | 超参数由训练者选择 |
| 损失函数 | 衡量预测与目标偏差的函数 | 训练损失低不等于泛化好 |
| 梯度 | 函数对参数的偏导数组成的向量 | 更新时通常沿负梯度方向 |

<!-- ui:tree title="知识的先修结构" -->

- 线性回归
    - 数学基础
        - 函数与向量
        - 导数与梯度
    - 建模
        - 预测函数
        - 损失函数
    - 评估
        - 验证集
        - 误差分析

<!-- ui:accordion title="读到这里可能会问" -->

- 为什么需要验证集？

    用未参与参数拟合的数据评估泛化，避免仅凭训练表现判断模型。

- 学习率越大越好吗？

    太大会跨过较优位置甚至发散；太小则收敛缓慢。应观察损失变化并结合条件分析。

<!-- ui:tabs title="换三个视角理解模型" -->

| 视角 | 核心问题 | 例子 |
|---|---|---|
| 几何 | 如何找一条贴近样本的直线？ | 最小化点到预测结果的误差 |
| 优化 | 参数朝哪个方向更新？ | 沿负梯度方向移动 |
| 统计 | 如何评估样本之外的表现？ | 使用独立验证集 |

<!-- ui:compare layout=auto title="从简单模型开始" -->

| 模型 | 表达能力 | 主要风险 |
|---|---|---|
| 线性模型 | 简单、易解释 | 对复杂关系可能欠拟合 |
| 高阶多项式 | 可以拟合非线性关系 | 数据不足时可能过拟合 |

## 推理：逐步算出来，再读代码

单样本平方误差使用 $L=(wx+b-y)^2$。下面暂把 $b$ 固定，只讨论对 $w$ 的偏导。

<!-- ui:derivation title="平方误差的梯度" -->

| 步骤 | 公式 | 理由 |
|---|---|---|
| 定义残差 | $r=wx+b-y$ | 明确中间变量 |
| 写成复合函数 | $L=r^2$ | 为链式法则作准备 |
| 求外层导数 | $dL/dr=2r$ | 幂函数求导 |
| 求内层偏导 | $\partial r/\partial w=x$ | 将 $b,y$ 视为常量 |
| 合并 | $\partial L/\partial w=2rx$ | 链式法则 |

<!-- ui:code title="一次梯度更新" -->

```python
prediction = w * x + b
residual = prediction - y
gradient = 2 * residual * x
w = w - learning_rate * gradient
```

| 行号 | 讲解 |
|---|---|
| 1 | 用当前参数得到预测值。 |
| 3 | 通过链式法则计算对 $w$ 的梯度。 |
| 4 | 沿负梯度方向更新；学习率控制步长。 |

<!-- ui:steps mode=steps title="把一次实验做完整" -->

1. 明确任务

    先给出可检验的目标，决定如何评价模型。

2. 划分数据

    参数拟合与效果评估使用不同的数据。

3. 训练并记录

    固定配置、随机种子和指标记录方式。

4. 分析结果

    查看典型错误案例，再决定下一次实验。

## 练习：主动回忆，不只重读

<!-- ui:flashcards title="先回想，再翻看" -->

| 问题 | 答案 | 补充 |
|---|---|---|
| 参数和超参数有什么区别？ | 参数从数据拟合；超参数由训练者选择。 | $w$ 是参数，学习率是超参数。 |
| 梯度下降沿什么方向更新？ | 负梯度方向。 | 局部一阶下降方向，仍需选择合适步长。 |
| 训练误差低能说明泛化好吗？ | 不能，还需要独立评估。 | 留意过拟合和分布偏移。 |

<!-- ui:cloze title="补全关键结论" -->

- 梯度下降通常沿 `负梯度` 方向更新参数。
- 不参与参数拟合、用于选择超参数的数据集称为 `验证集`。

<!-- ui:match title="概念和用途配对" -->

| 概念 | 用途 |
|---|---|
| 训练集 | 拟合模型参数 |
| 验证集 | 选择配置和超参数 |
| 测试集 | 最终独立评估 |

<!-- ui:quiz type=multi answer=A,C title="哪些做法有助于可靠评估？" -->

下面哪些做法有助于评估模型的泛化能力？

- A. 将评估数据与训练数据分开
- B. 只报告训练误差
- C. 检查不同类型的错误案例

> A、C 正确。训练误差可以帮助排查拟合问题，但不能单独代表泛化表现。
