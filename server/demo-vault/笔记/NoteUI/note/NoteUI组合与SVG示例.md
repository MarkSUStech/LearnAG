## 逐行理解

<!-- ui:code -->

~~~python
def traverse(node):
    while node is not None:
        print(node.value)
        node = node.next
~~~

|行号|讲解|
|---|---|
|1|接收当前首节点，空链表用 None 表示。|
|2|每次访问前先判空，防止读取不存在的节点。|
|3|读取并输出当前节点保存的值。|
|4|沿 next 前进一格，保证最终到达链尾。|

<!-- ui:steps -->

1. 保存后继：tmp ← p.next

    修改指针前先保留原来的后继，防止丢失后半条链。

2. 接入新节点：p.next ← q

    前驱开始指向新节点，此时还需要完成下一步。

3. 重新接通：q.next ← tmp

    得到 46 → 32 → 51，整个改链过程只需常数次赋值。
