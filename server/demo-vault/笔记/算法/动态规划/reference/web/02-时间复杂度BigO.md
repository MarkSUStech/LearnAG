# 时间复杂度 Big O 分析核心知识

## 什么是 Big O

大 O 记号根据输入大小增加时算法运行时间的增长趋势来分类算法。关注的是**增长趋势**，忽略常数系数与低阶项。

## 常见复杂度（由快到慢）

| 复杂度 | 含义 | 典型场景 |
|---|---|---|
| **O(1)** | 常数时间 | 数组首元素访问、哈希表查找 |
| **O(log n)** | 对数时间 | 二分查找（每次迭代范围减半） |
| **O(n)** | 线性时间 | 遍历数组找最大值 |
| **O(n log n)** | 线性对数 | 归并排序（分治 + 合并） |
| **O(n²)** | 平方时间 | 双重循环遍历二维结构 |
| **O(2ⁿ)** | 指数时间 | 无记忆化的斐波那契递归 |
| **O(n!)** | 阶乘时间 | 全排列生成、旅行商问题暴力解 |

## 核心规则

- 忽略常数因子：$O(2n) = O(n)$
- 只保留最高阶项：$O(n^2 + n) = O(n^2)$
- 多变量时分别保留：$O(n \cdot m)$

## 分析方法

- 数循环嵌套层数（嵌套 k 层 → $O(n^k)$）
- 递归看分支：每次递归产生 b 个分支、深度 d → $O(b^d)$
- 二分/折半 → $O(\log n)$
- 分治 → $O(n \log n)$

## 实用记忆口诀

> 常对线、平方立方指数阶；阶乘最慢到天涯
