# 记忆化搜索（Memoization Search）核心知识

## 定义

记忆化搜索是一种通过存储已经遍历过的状态信息，避免对同一状态重复遍历的搜索算法。它是动态规划的一种"自顶向下"实现方式。

## 核心思想

- 普通递归（如斐波那契数列）会重复计算大量子问题
- 记忆化搜索 = 递归 + 缓存（数组/哈希表），每个状态只计算一次
- 本质：**空间换时间**

## 与动态规划的关系

| | 记忆化搜索 | 递推（自底向上 DP） |
|---|---|---|
| 方向 | 自顶向下 | 自底向上 |
| 实现 | 递归 + memo | 循环 + dp 数组 |
| 优点 | 代码清晰，适合复杂状态转移 | 无栈溢出风险，顺序明确 |
| 缺点 | 递归深度过大可能栈溢出 | 复杂状态转移方程难以实现 |

## 四步法

1. 写出状态定义与状态转移方程
2. 定义缓存（数组/哈希表）
3. 定义递归函数：先查缓存 → 有则返回 → 无则计算并存储
4. 主函数调用递归函数返回结果

## 经典案例：斐波那契数列

```
fib(5) 普通递归：
- f(5) = f(4) + f(3)
  - f(4) = f(3) + f(2)
    - f(3) 被重复计算多次 ← 瓶颈

记忆化搜索：memo[n] 存储已计算结果，f(3) 只算一次
```

## LeetCode 实战

- **494. 目标和**：DFS + memo，状态为 (i, cur_sum)，避免 $O(2^n)$ 爆炸
- **1137. 第 N 个泰波那契数**：$T(n) = T(n-1) + T(n-2) + T(n-3)$，memo 数组缓存

## 复杂度

- 时间：$O(n)$（每个状态只算一次）
- 空间：$O(n)$（缓存 + 递归栈）
