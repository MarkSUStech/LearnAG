# LearnAgent 工作台初稿

## 已确认范围

以笔记阅读为中心的个人学习工作台。侧边 AI 支持讲题、读图、生成与修改笔记；本轮交付可交互页面，后续依据反馈替换正式界面。

## 后端与界面映射

| 用户任务 | 初稿位置 | 现有接口 / 模块 |
|---|---|---|
| 找到笔记与教材 | 学习空间、笔记库、搜索 | GET /api/tree、GET /api/file、GET /api/ide/search |
| 阅读、修改原始笔记 | 中央阅读区、源码切换 | RichText、NoteUI、PUT /api/file |
| 针对材料提问 | 右侧 AI 协作、材料范围 | POST /api/tutor、GET /api/tutor/session |
| 连续教学与历史 | AI 对话 | /api/teacher、/api/teacher/sessions |
| 上传题图 | AI 输入区的图片附件 | POST /api/upload、全局 vision 链路 |
| 多文件写作任务 | 生成与改写操作、运行记录 | POST /api/agent、/api/events、/api/agent/answer |
| 学习目标 | 学习路径 | GET /api/goals、GET /api/plan |
| 知识关联 | 知识图谱 | GET /api/graph、GraphView |
| PDF 标注与卡片 | 资料阅读 | PdfStudyPane、/api/pdf-study/* |
| 代码调试 | 进入现有代码工作区 | IdeShell、/api/run、/api/lsp |
| 模型与显示设置 | 底部设置入口 | /api/settings、appearance |

## 初稿边界

文件树、笔记阅读、目标和知识图谱可读取当前后端。样例交互、AI 回复与源码修改先在预览中演示，界面明确标识，不调用付费模型、不写回真实笔记。AI 内部提示词、工具循环、历史存储与模型配置继续沿用现有能力。

## 运行与查看

沿用项目已有的前后端启动方式，在前端地址后加 `?design=workspace`。本次验证地址为 `http://127.0.0.1:3100/?design=workspace`；去掉参数进入原界面。入口通过 `src/main.tsx` 懒加载，未替换默认应用。

用户已选择“研习记录台”：暖白阅读面、墨色文字、赤陶色主要操作。桌面让资料导航、阅读、AI 协作并列；手机通过抽屉按需展开导航和 AI。

| 本轮实际接入 | 交互演示 / 后续接入 |
|---|---|
| 文件树、打开 Markdown、知识图谱、学习目标、模型名称 | AI 回复、工具运行记录、笔记改写 |
| 阅读器、NoteUI、KaTeX，源码切换 | 预览草稿仅保存浏览器 `la-design-draft`，不写笔记库 |
| PDF 通过现有原始文件接口打开新标签 | 完整 PDF 标注与 IDE 仍在原界面 |
| 图片选择、粘贴、拖入的本地预览 | 实际上传、视觉识别和历史持久化尚未接入新界面 |

上方接口映射表列出已有后端的对应能力，不代表本轮已经调用其中的写入、上传与模型接口。

## 验证记录（2026-10-19）

生产构建通过。浏览器验证覆盖桌面 1440 / 1280、手机 390、暗色外观；搜索并打开真实笔记、资料筛选空状态、真实图谱与目标、源码草稿保存后恢复、交换样例代价 0→1→3 与重置、NoteUI 自测正确反馈。样例及真实笔记未检测到 KaTeX 错误。

独立设计验收提出三项修正：自托管展示字体、移除标题前的重复分类行、统一自测反馈边框。修正后重新构建（55.36 秒）并复拍同一组五张截图，复核结论为 `ship`，三项均已解决。验收记录在 `.impeccable/review/finish-review.md`；该结论的范围是这三项修正。

标题使用本地 Noto Sans SC 600 子集（16,720 字节，附 SIL OFL 许可）；浏览器确认字库加载及主要中文标题字形可用。正文继续使用原系统字体。任意用户笔记标题超出子集的字形会使用中文回退字体，正式采用时可扩展分段字库。

本轮未做操作系统图片选择器和真实视觉模型的端到端验证。全项目 TypeScript 检查仍存在 `src/components/ide/lspBridge.ts` 第 237、320 行的既有错误；新增预览模块未产生 TypeScript 错误。大体积图谱 / Mermaid 分包告警沿用现有依赖，后续正式接入时可单独优化。

## AI 交互设计

- 始终可见当前材料范围；从笔记发起的问题携带笔记上下文。
- “讲解 / 推导 / 自测 / 整理”是目的入口，内部角色与工具细节按需展开。
- 读图先展示缩略图，支持移除；上传、识别、生成和写入分开反馈。
- 修改笔记先给可查看的改写结果，写入目标路径与完成状态明确可见。
- 渐进展示来源、答案解析、原始 Markdown；普通解释保持自然段落。
- 新界面不增加分类、格式转换或纯装饰性的模型调用。
