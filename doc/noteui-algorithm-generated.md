**结论**：交换次数被固定为逆序对数。任意一对逆序 (x 在前、y 在后且 x>y)，二者必须先相邻再直接交换一次才能颠倒相对顺序，代价 = min(x,y) = y。因此**最小代价 = Σ 每个逆序对中较小者**，等价于 Σ aᵢ ×（其左侧比它大的个数），无策略可选。

<!-- ui:steps mode=steps -->

1. 从左到右扫描，统计每个 aᵢ 左侧严格大于它的元素个数 cᵢ
   用树状数组（先离散化 aᵢ≤10⁹）或归并排序求逆序对，O(n log n)。
2. 累加 ans += 1LL * aᵢ * cᵢ
   上界约 5×10¹⁸，必须用 long long。
3. 输出 ans

<!-- ui:table -->

|步骤|序列状态|操作|代价|
|---|---|---|---|
|初始|[3,1,2]|—|0|
|处理 1|3 在左且更大|swap(3,1)|min(3,1)=1|
|处理 2|[1,3,2] 中 3 在左更大|swap(3,2)|min(3,2)=2|
|结束|[1,2,3]|已升序|合计 3|

走查 [3,1,2]：1 的左侧有 1 个更大的数（3）→ 贡献 1×1=1；2 的左侧有 1 个更大的数（3）→ 贡献 2×1=2；3 无贡献。**ans=3**，与手算一致。

C++ 思路：`sort` 版离散化 + Fenwick，查询 `i-1 - query(rank)` 得逆序数即 cᵢ，再乘权累加即可。
