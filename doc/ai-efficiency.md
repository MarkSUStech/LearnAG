# NoteUI 默认策略与 AI 调用优化

2026-10-19。在现有生成链路中增量调整，无新依赖或模型调用，无笔记迁移。

## 默认使用

结构化学习内容默认选择 NoteUI（20 类组件）；普通讲解继续 Markdown，短答不强制组件，用户指定格式优先。共享语法位于 `server/agent/noteuiPrompt.js`，API 主助手、ZCode、教学、答疑和写作角色复用。资源角色只需资源表格语法，研究角色不携带组件清单。

## 调用逻辑

- 删除主助手每轮先发起的模型路由请求。明确寒暄走本地规则，其余交给主模型在同一次回答中决定工具；附件、目标、写作模式、承接任务的「好的/继续」保留工具能力。
- 常规笔记允许主助手直接 `write_note`。复杂任务才按需委派，不再要求写作后固定配图、重排和润色；已明确写入成功且无疑点时不强制重读全文。
- 主助手从17个工具缩为10个；外部资料/配图通过已有专职角色获取，文件管理与图谱仍可直接操作。答疑从17个缩为4个（读/写笔记、知识检索、读图谱）；教学保持已有8个。执行端同步检查角色工具范围。
- 写完笔记的回报与委派交接只给路径、必要事实和未解决事项，减少同一篇正文反复生成、传入下一个角色。
- 教学提示从原英文长篇范式提炼为中文规则；保留引导学习、一次一个问题、受挫/明确要求时直接解释、来源引用和安全纪律。三种答疑角色保留各自关键规则。
- RAG 仍自动检索，去除重复命中、最多4条、每条500字符，保留来源/页码并标明节选；进一步细节可按路径读取。
- 较早轮的长工具结果只在请求视图中节选；成功历史写入的长正文替换为路径提示。当前轮工具结果、思考字段、用户输入、失败记录均完整保留，调用与结果配对不变。不会拿节选覆盖笔记。旧版已经截断的数据无法自动恢复。
- 移除原先保存历史时截短旧工具结果的逻辑；保留现有长会话滚动摘要机制，修复合并摘要重复追加、空摘要仍丢弃旧消息的问题。直答历史与主助手最终回复现在会完整进入会话。
- 教学、答疑、子角色在工具续轮保留模型要求的 `reasoning_content`，教师委派沿用教师选择的引擎，减少不一致导致的失败重试。

## 可复现测量

运行 `node scripts/measure-agent-context.mjs`。以下仅比较相同空动态上下文下的 **JavaScript 字符数**；工具定义按 JSON 序列化。中英文 tokenizer 不同，这些比例不能视为实际计费 token 比例。

| 项目 | 修改前 | 修改后 | 字符减少 |
|---|---:|---:|---:|
| NoteUI 共用语法 | 2638 | 1628 | 38.3% |
| 教学静态提示 | 15157 | 2613 | 82.8% |
| 快讲答疑静态提示 | 3528 | 2121 | 39.9% |
| 主助手工具定义 | 7705 | 4740 | 38.5% |
| 答疑工具定义 | 7705 | 1625 | 78.9% |

主助手提示因新增完整 NoteUI 默认规则从1785增长到2537字符，提示+工具合计仍从9490降到7277（23.3%）；快讲答疑提示+工具从11233降到3746（66.7%）。最新规则补全了对比/测验示例、英文参数约束与公式竖线写法。实际还会叠加笔记、图谱、资料和对话，具体费用需供应商 usage 才能确认。

模拟接口实测：普通寒暄只发起1次流式请求（原先还需1次分类）；直接创建并保存 NoteUI 笔记发起2次（生成工具调用、读取成功结果后收尾），不触发委派。复杂任务次数仍取决于真实工具需求，不固定为2次。

## 验证与使用

- `npm run test:agent`：14项通过，含真实主助手/答疑循环与模拟OpenAI流式接口；使用临时知识库，不访问付费模型或修改用户配置文件。
- `npm run test:noteui`：33项通过，覆盖20类组件、公式竖线保护及混合Markdown解析。
- `npm run build`：生产构建验证。

修改后需要重启现有后端进程以加载新提示词。使用原入口生成笔记即可，无需增加AI调用或手动开关。已用当前 `deepseek-v4-flash` 做短样本冒烟：首轮发现模型把 `answer` 翻译成中文，补充约束与测验示例后，第二轮直接生成可解析的 compare 与 quiz。第二轮实际usage为输入932、输出494（含214推理）、合计1426 tokens；首轮1550 tokens。两次仅用于本次验证，不加入正常生成链路。

样本见 [真实模型生成的复习笔记](noteui-generated-sample.md)。可选复验：`node scripts/check-noteui-live.mjs --run`，每次明确执行只发起一次配置模型请求；默认不带 `--run` 不调用模型。短样本不能代表所有场景的长期遵循率或费用降幅，不合规指令仍安全回退普通Markdown。
