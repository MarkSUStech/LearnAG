# 工作区与阅读连续性

默认应用 `/` 保留原有文件树、标签与阅读界面，真实 AI 全局对话和当前笔记/PDF 答疑都位于右侧栏；底部浮动输入框已移除。`?design=workspace` 是早期视觉草稿，不是功能验收入口。

## 自动恢复

- 按资料库保存打开的标签、活动文档、分屏文档、分屏比例、文件侧栏/AI 侧栏宽度、开合和答疑范围。180ms 防抖，在 pagehide/页面可见性变化时同步刷新保存。
- 重开时从真实文件树校验路径，已删除文档不恢复，笔记仍加载服务端最新内容。读取失败时提供重试，不覆盖原版面记录。没有打开标签的状态也会保留。
- 大屏和窄屏分开判断开合恢复，避免桌面的已展开面板在手机遮住阅读；手机打开 AI 时收起文件抽屉。关闭面板后归还焦点，关闭内容设 inert。
- 文件夹展开状态按资料库和路径记忆。
- Markdown 保存请求按文件串行，失败保留待重试内容；Ctrl+S 只有实际写入成功才提示已保存。内容不是离线持久草稿，不承诺断网刷新可恢复未保存的正文。

## PDF

- 每份 PDF 保存页码、页内位置，恢复时把同一个文档点放回视口 1/3 处；包括第一页。
- 长文档等待目标页尺寸加载后再恢复，加载最初几页时不会把深页记录覆盖掉。用户滚轮/触摸主动阅读可取消待恢复；明确引用跳转优先于历史位置，旧引用消费后不会在重开时重复跳转。
- 缩放、大纲/卡片面板开合、面板标签也会记忆。每个 PDF 独立 provider/加载引用，支持切换和分屏。
- 页码框可直接输入并按 Enter 跳转，错误范围有反馈，Escape 恢复当前页。
- 标注/卡片加载完成后才允许自动写回；保存串行，离开/隐藏时提交待保存更改，避免仅取消防抖导致丢失。关闭页的 keepalive 仅用于不超过 60kB 的请求，不替代服务端持久化确认。

目前 PDF 阅读偏好和笔记滚动位置使用既有的文档相对路径键；不同 vault 中同名相对路径可能共享此类阅读位置。版面和文件树状态已按 vault 隔离。浏览器清除站点数据、隐私模式或禁止 localStorage 会丢失本机偏好，但不影响 Markdown 文件。

## 已验证

真实 848 页 PDF 跳到第 160 页，缩放到 144%，展开大纲并滚动页内；刷新后活动 PDF、两枚标签、AI 收起、大纲、页码、缩放均恢复，滚动位置偏差小于 1 CSS 像素。单元测试另外覆盖第一页、尚未加载的深页、非法本地数据及存储不可用的降级。

PDF 文字选择重影：全局 `::selection` 仅设置背景，保留 PDF 透明文字的前景色；旧文字层在缩放/卸载时取消渲染，并按 PDF 和页码校验缓存。在 `dsaa_L04_linkedlist.pdf` 第 4 页选择“Have to specify an initial array size”，可正常高亮和标注，无第二层黑字；连续缩放后同句只保留一个透明 span。
